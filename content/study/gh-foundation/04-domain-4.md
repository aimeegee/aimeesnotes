## [GitHub Codespaces](https://github.com/Andresmup/github-foundations/blob/main/20_CODESPACES/Readme.md)

What is?
  * Github Codespaces is a Cloud Development Environment (CDE) integrated with your Github repo.
  * In Ubuntu Linux docker container on a virtual machine hosted and managed by Github

Interact with codespaces
  * Your codebase will be cloned into /workspaces
  * You can see all of your codespace at https://github.com/codespaces
