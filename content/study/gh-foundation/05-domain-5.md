# [Projects](https://github.com/Andresmup/github-foundations/blob/main/22_PROJECTS/Readme.md)

## PROJECTS VS CLASSIC PROJECTS

## What can we do with project:
* Can use workflow to manage project. E.g. auto add issues, update status
    * Build in workflows
    * Advanced - use GitHub Action
* Projects directly integrates with Issues and Pull Requests. Integration sync happens both ways between PR/issues and project.
* Can add draft issue - useful to quickly collect ideas, doesn’t belong to a repo. Only exist in projec
* Can create iteration task
* Set priority (High, medium, low), group issues by priority
* different views - roadmap, table, board

## Add issues
* supports add to project by copy issue url, add by auto workflow
* Supports search, can search the repo where issue belongs to
* bulk add issues by using filter

## Saved replies
* to easy apply replies you frequently used over and over
* In settings -> Code, planning, and automation
